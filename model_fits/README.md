## Model fit files

If you are viewing this repository on GitHub, the `.rds` model-fit files are not included here because GitHub does not like large files.

For the complete repository, including the `model_fits/` `.rds` files, use the OSF archive:

https://doi.org/10.17605/OSF.IO/3M6FU

If you are working from the GitHub copy, you will need to download the full repository from OSF or rerun the analysis scripts to regenerate the model fits locally.
